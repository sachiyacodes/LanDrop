# Security reporting

Report sensitive security issues through [GitHub private vulnerability reporting](https://github.com/sachiyacodes/LanDrop/security/advisories/new). Private reporting is enabled for this repository. Do not post credentials, personal data, or exploit details in public issues.

Include the affected source commit or release, reproducible steps using synthetic data, and the expected impact. Remove secrets from logs and screenshots. This portfolio project has no guaranteed response time or security-support contract.

Only the current default-branch source is actively maintained. Release notes state each release's tested scope and limitations; older downloads do not receive silent updates. Dependency-update pull requests require review and passing CI before merging. No automatic merge or package publication is configured.
